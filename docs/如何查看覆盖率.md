# 📊 如何查看测试覆盖率报告

## 方法1：本地查看HTML报告（推荐）

### 步骤：

```bash
# 1. 激活虚拟环境
cd /home/palizha/SoftSec-Tatou-Group18
source server/test_venv/bin/activate

# 2. 运行测试并生成覆盖率报告
pytest tests/ --cov=server/src --cov-report=html:coverage/htmlcov --cov-report=term

# 3. 启动本地服务器
cd coverage/htmlcov
python3 -m http.server 8080

# 4. 打开浏览器访问
# http://localhost:8080
```

### 预期结果：

- 总体覆盖率: 72%
- server.py: 78%
- watermark_attachment.py: 79%
- watermark_metadata.py: 80%

## 方法3：查看覆盖率总结文档

直接查看项目根目录的 `COVERAGE_SUMMARY.md` 文件，包含：
- 📊 总体覆盖率统计
- 📈 各模块覆盖率详情
- ✅ 测试文件列表
- 📅 改进历程

## 为什么GitHub上没有coverage文件夹？

✅ **这是正确的！**

覆盖率报告是**生成的文件**，不应该提交到Git仓库：
- 已在 `.gitignore` 中排除（第40行：`htmlcov/`）
- 每次运行测试都会重新生成
- 文件很大，会让仓库臃肿
- 这是行业标准做法

## 如何给老师展示覆盖率？

### 选项1：让老师本地运行（最可靠）
```bash
git clone <your-repo>
cd SoftSec-Tatou-Group18
source server/test_venv/bin/activate
pytest tests/ --cov=server/src --cov-report=term
```

### 选项2：提供覆盖率截图
- 在 `docs/screenshots/` 目录下保存覆盖率截图
- 这些截图可以提交到Git

### 选项3：查看COVERAGE_SUMMARY.md
- 已包含所有覆盖率数据
- 已提交到仓库，老师可以直接查看

---

**结论**: coverage文件夹不在GitHub上是**完全正常**的，老师可以通过以上3种方式查看你的覆盖率成果。
